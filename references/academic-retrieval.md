# Live academic retrieval

For each academic rewrite, after the baseline and before the first candidate, identify the passage's function, language, and register. For a long essay, identify the main section types and prioritize the sections that need revision.

1. If Google Scholar is accessible through browser tools, search it first. Use generic search terms describing the section and design, such as "comparative observational study abstract weighted averages". A close match in rhetorical purpose is sufficient across disciplines. Do not send the user's draft, unpublished findings, or identifiable details as search queries.
2. Default to papers published through 2021. Use the user's date range when supplied. Select one or two promising papers per relevant passage type. Open and read the actual abstract or relevant section from the publisher, open-access copy, or institutional repository. Verify the date and title and record the URL or DOI. Use abstracts only for features you can verify from those abstracts.
3. When Scholar is inaccessible because a supported browser permission is missing, ask the user for that access before falling back. If denied or unavailable, or the site still blocks access, use available scholarly search tools or search publicly indexed journal and repository pages. Apply the same date and source checks. If no source can be read, use the bundled academic style guide and disclose that fallback.
4. Record two or three style observations per useful example, such as how a methods section defines its unit of analysis or how a results section pairs figures with group labels. Apply the patterns in original language. Do not reuse distinctive sentences, import facts, or insert new citations into the user's draft merely because the papers informed its style.
5. Reuse verified notes within the same run. If three measured candidates in a row fail to improve the best score, run one new targeted query for a different writing pattern or section. Do not repeat an already exhausted query. If retrieval is unavailable, continue with the verified notes or bundled guide.
6. In the final report name the discovery route and link the papers actually read. Distinguish what you read live from any bundled examples. Claim no Scholar search if only a fallback was used.

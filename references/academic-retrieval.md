# Live academic retrieval

After attempting the baseline and before drafting the first academic revision, identify the target section, language, register, and writing problem. For an essay, prioritize the sections that need the most work.

1. Search Google Scholar first when accessible. The eligible pool includes any paper indexed by Scholar and published in 2021 or earlier, across fields. Apply the user's date range or other constraints when supplied. Set an inclusive upper publication year of 2021 by default and use task-specific queries. Use generic phrases such as "comparative observational study abstract weighted averages". Exclude the user's draft, unpublished findings, and identifying details from queries.
2. Rank eligible candidates in this order:
   - Closely relevant peer-reviewed work in established journals or conferences with verifiable publisher or institutional provenance.
   - Established peer-reviewed work from other topics or disciplines when its section and study design provide a useful writing example.
   - Identifiable preprints, theses, or other credible scholarly work in reputable repositories when stronger candidates lack readable examples. Record the source type.
   Within each tier, prefer a closer match to the passage's function, methods, field, and language. Use citations as a secondary signal. Prefer a publisher version or verified author or institutional copy over an unattributed mirror.
3. Select one or two examples per relevant section type. Verify title and year and record the DOI or URL. Read the actual abstract or relevant section. If only the abstract is available, use it only for patterns visible there. If no suitable example is readable, move down the source ranking.
4. If a supported browser permission is missing, ask for access before falling back. If denied, unavailable, or Scholar still blocks access, search other available scholarly indexes or publicly accessible journals and university repositories. Apply the same date and ranking rules. Use the bundled academic style guide when no source is readable, and report that fallback.
5. Record two or three transferable writing observations per example. Apply the patterns in original wording. Preserve the user's claims, data, citations, and qualifications. Do not insert sources solely because their prose informed the draft.
6. Reuse notes within the run. After three measured candidates without a new best on the same detector and scope, run one targeted search for a different structure or a section that needs attention. Avoid repeating exhausted queries.
7. Report the discovery route and link the papers actually read. Identify any offline fallback.
